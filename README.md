## 📖 專案簡介 (About)

本專案為個人專業品牌履歷網站，旨在展示身為 **Japan PM（日本市場導向專案經理）** 的核心專業優勢、職涯經歷與跨文化溝通價值。

網站採用現代化前端技術與響應式設計（Responsive Web Design），完美結合硬核的專案管理經歷（如記憶體產業 OEM NPI、價格審核與風險控管）以及軟實力的跨國橋樑角色（如日商總公司對接、法務稅務協調與品牌行銷導入）。

## ✨ 核心特色與功能 (Key Features)

- 🎨 **現代化玻璃擬態介面 (Glassmorphism)**：結合 Tailwind CSS，提供乾淨、專業且具備科技感的視覺體驗。
- 🌓 **動態深淺色主題切換 (Dark/Light Mode)**：支援使用者自由切換夜間模式與日間模式。
- ⚡ **即時客製化預覽 (Live Customizer)**：訪客可直接在頁面上輸入姓名並即時套用，提供高度互動性。
- 📱 **完整響應式設計 (Mobile-Friendly)**：手機版、平板與桌面皆能流暢瀏覽，排版精緻。
- 🔍 **最佳化 SEO 與 AEO / GEO 結構化數據**：內建完整的 Open Graph、Twitter Cards 與 Schema.org (`Person` / `WebSite` JSON-LD)，利於搜尋引擎與 AI 引擎（AEO）進行內容解析與索引。
